# Decisiones de diseño

## 2026-08-20 — Alcance inicial

- Se implementará primero el alcance **A**: análisis del G-code y recomendaciones.
- Las estructuras internas deben permitir posteriormente:
  - **B:** comparación entre perfiles/análisis.
  - **C:** aplicación asistida de cambios.
- El MVP no modificará perfiles ni G-code.
- El análisis será local y asíncrono.
- La estimación inicial será rápida y basada en movimientos del G-code.
- Las recomendaciones serán explicables y basadas en reglas.
